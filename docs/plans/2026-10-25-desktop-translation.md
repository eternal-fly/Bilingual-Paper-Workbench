# Desktop-owned paper requests and complete translation

The workbench sends explicit author requests to the existing Desktop chat. Desktop owns inference, model settings and conversation history. The plugin supplies protected text, tracks progress and validates returned translations or revision candidates. It never resumes that chat through a competing inference process.

- Verify the installed official durable thread queue with one authorized translation. The producer may initialize, read exact metadata and enqueue; it may not start/resume a thread, start a turn, change settings or use model tools. Distinguish queue acknowledgment from completed execution. Uncertain delivery never automatically resends.
- Keep originating-chat discovery, source/paper identity and saved records. Desktop mode binds verified metadata without acquiring a writer. An explicit click can open the bound Desktop chat for model changes.
- Add one full-paper translation action and selected/range translation without an eight-paragraph user limit. Preserve the ordered complete paragraph manifest. One Desktop request drives bounded internal get/submit batches until all requested paragraphs are returned.
- Persist tasks, batch identities and progress. Protect equations, references, alignment, language, source hashes and manual draft revisions. Duplicate results acknowledge once; source/manual changes, cancellation and stale generations cannot overwrite drafts. Resume is explicit and keeps completed paragraphs.
- Send discussion and selected revision/sync requests through the same Desktop queue. Returned text and candidates are scoped to their exact approved request and never grant source-write authority.
- Reproduce the old manual-copy route and stale-channel binding in browser regressions. Verify more than eight selected paragraphs, full-paper coverage, cancel/resume, protected atoms, safe source boundaries and the real Desktop return path before installing the update.

Use the existing Windows/Node/MCP implementation and reading layout. New controls and documentation default to English. Existing manual and embedded compatibility routes remain explicit for hosts without Desktop delivery. No public release, commit or push is authorized.
