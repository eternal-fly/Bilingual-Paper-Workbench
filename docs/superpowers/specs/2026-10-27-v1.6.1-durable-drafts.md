# Durable author drafts and adaptive source review

Version 1.6.0 let source-authority checks reject a translation save when deleting an ordinary sentence containing nonbreaking spaces. Author text and source-write authority must be separate.

## Behavior

- Save the exact bounded author paragraph under current paper/draft CAS and native capture checks. Incomplete math, unknown references, malformed formatting and unproved project macros are source-review diagnostics, not reasons to lose a durable draft.
- Keep Saved, reading/editing, native capture and reopen usable; distinguish source review from storage/permission failure. No model-only metadata can grant author authority.
- Proven ordered omissions of existing safe inline atoms may generate normal protected candidates even when unrelated project macros prevent a global builtin proof. No new invocation is authorized by omission.
- Other unresolved edits remain candidate-ready through an adaptive request with exact raw draft, original source and a validated protected baseline. Codex can adapt prose and source format using project context; file/exec controls, critical bindings and unproved new commands cannot be invented.
- Compile and confirm the exact candidate before source/PDF promotion. A partial adaptation must retain unresolved author intent and receive no all-applied receipt. Later edits/repair/rebase/undo must not silently discard it.
- Preserve the current unsaved real-paper window. All acceptance uses newly written synthetic TeX/reviews/translations, not the author manuscript.
