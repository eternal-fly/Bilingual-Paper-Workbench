# Free Editing and One-click Writeback Implementation Plan

**Goal:** Let the author freely edit inline TeX and use one explicit click to save current intent, generate English, compile, write source and update the latest PDF; keep post-write statuses accurate and export current TeX/PDF.

**Architecture:** Keep the existing Windows/Node/MCP stack. A durable background task captures the human click and exact saved scope, uses the bound Desktop chat once, then compiles and applies that exact task result without another review modal. The model receives no general source-application tool. Content locks are removed; version/hash/file identity, atomic recovery and OS compiler isolation remain data-integrity boundaries.

**Tech Stack:** Existing Node.js 24, MCP SDK, plain JavaScript/CSS, isolated TeX worker and browser tests.
