# Bilingual Paper Workbench 1.6.0 Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans task by task. Keep each independently owned component's test cycle separate and review the integrated behavior before release.

**Goal:** Editable inline structures, responsive paragraph editing and genuine display-only PDF magnification, without regressing accepted source/PDF associations.

**Architecture:** Extend the existing protected author-intent pipeline and recoverable drafts. Keep input work local to the active editor and reuse immutable document derivations. Separate PDF CSS view scale and bounded raster rendering, using generation guards and exact viewer identity for async work.

**Tech Stack:** Existing Node.js 24, ES modules, native DOM/CSS, PDF.js, Markdown/KaTeX, native MCP and the isolated Windows TeX compiler. No new framework or external UI assets.

**Spec:** `docs/superpowers/specs/2026-10-27-v1.6-editing-and-zoom-design.md`.

## Global constraints

- Target version `1.6.0`; English default UI and documentation.
- Keep source acceptance and undo authenticated human UI actions.
- Keep private paper/state/configuration and parent-repository history out of distribution.
- Reuse the standalone plugin directory; the parent checkout contains unrelated untracked work. Do not stage or reset that parent.
- Test using synthetic manuscripts only; preserve the user's real project and active unsaved window.

## Review focus

- An incomplete structure edit must remain editable and recoverable after validation fails.
- An older save/render/capture response must not replace newer input or another project/PDF.
- New inline author intent must survive unrelated writes, invalidate obsolete approvals, and remain pending after undo.
- Zoom/pan must not move a source-location target or consume ordinary reading scroll and clicks.
- Large paragraphs, many labels and frequent status updates must not repeatedly scan or repaint the whole document.
